# 广义表探险 · 拓展链表型广义表分步可视化

一个纯 HTML / CSS / JavaScript 实现的教学工具：左侧用分步动画展示拓展链表型广义表的解析、求长、求深、取表头、取表尾和遍历；右侧只显示当前操作的核心 C 代码，并同步高亮当前行。

所有操作都会先生成“步骤快照数组”，再由播放器按步骤渲染，不会一次性画完最终图。

## 运行方式

无需安装依赖、无需后端：

1. 直接打开 `index.html`；
2. 或使用任意静态服务器，例如：
   ```bash
   python -m http.server 8080
   ```
   然后访问 `http://localhost:8080/`。

推荐使用当前版本的 Edge、Chrome 或 Firefox。页面面向 1366×768 及以上屏幕设计，小屏幕会自动调整布局。

## 输入语法

- 广义表必须由一对匹配的括号括起来；
- 原子为单个字母、数字或下划线；
- 空白会被忽略；
- 逗号分隔同级元素；
- 空表写 `()`；
- 不支持多字符原子、方括号、引号等扩展语法。

合法示例：

```text
(a,(b,c),d)
((a,b),c,d)
(x,(y,z),(p,(q)),r)
()
(a)
  ( a , ( b , c ) , d )
```

非法示例会在输入框下方显示具体字符位置，不会导致页面崩溃：

```text
(a,b      缺少右括号
(a,,b)    逗号后缺少元素
(a b)     元素之间缺少逗号
a         顶层必须是括号表
(a)b      顶层右括号后还有内容
```

## 操作与结果

| 操作 | 说明 | 示例 `(a,(b,c),d)` |
|---|---|---|
| 创建 / 解析 | 递归下降解析并逐步构建节点图 | 根表 + 3 个顶层元素 + 嵌套子表 |
| 求长度 | 沿根节点 `child` 链统计顶层元素 | `3` |
| 求深度 | 按本页层数口径递归求最大层数 | `3` |
| 取表头 | 返回根节点的 `child` | `a` |
| 取表尾 | 返回首元素之后的剩余表 | `((b,c),d)` |
| 遍历 | 先序访问原子，表节点只作为路径 | `a, b, c, d` |

### 深度口径说明

本页按原始验收要求，对 `(a,(b,c),d)` 显示深度 **3**，采用“层数口径”：

- 空表深度为 1；
- 原子节点计 1 层；
- 表节点深度 = `1 + max(所有子元素深度)`。

教材常见的“括号重数口径”通常把原子深度记为 0，同一表达式会得到 2。经典题库中涉及深度的题目会同时注明两种口径，避免混淆。

## 节点与箭头图例

节点：

- 原子节点：绿色圆形，显示字符、`ATOM` 和节点 ID；
- 表节点：蓝色矩形，显示 `表`、`LIST` 和节点 ID；
- 表尾返回值：橙色虚线框，显示在画布底部“返回值”区域；
- 当前节点：橙色描边、阴影放大；
- 遍历访问过的原子：绿色勾选徽标。

箭头按语义分类，颜色、线型和文字同时区分：

| 指针 | 颜色/线型 | 文字标签 | 含义 |
|---|---|---|---|
| `child` | 蓝色实线 | `child` | 表节点指向自己的首个子元素 |
| `next` | 琥珀色虚线 | `next` | 指向同级下一元素 |
| 当前高亮指针 | 红色加粗、流动虚线 | `child` / `next` | 当前步骤正在操作的指针 |

### 长度和深度的图像化展示

- **求长度**：
  - 每统计一个顶层元素，就在节点左上角增加 `#1`、`#2`…徽标；
  - 画布右上角实时显示 `len = n`；
  - 当前元素与 `next` 指针同步高亮。
- **求深度**：
  - 每个节点计算完成后，在左上角显示 `d1`、`d2`…深度徽标；
  - 画布左侧显示 `第 1 层 / 第 2 层 / 第 3 层` 层号标尺；
  - 当前递归所在层会高亮；
  - 画布右上角实时显示 `max`、`child`、`depth` 等中间量。

## 步骤快照

每个操作在播放前都会生成完整数组。基本结构：

```js
{
  desc: "沿 next 指针移动到下一个元素",
  codeLine: 8,                    // 当前核心代码块中的 1-based 行号
  nodes: [ /* 当前节点快照数组 */ ],
  highlightNodeIds: ["A2"],
  highlightPointers: ["L1.child", "A2.next"],
  variables: { p: "L3", len: 2 },
  result: "len = 2",

  // 以下为可选扩展字段
  visitedIds: ["A2"],             // 遍历中已经访问过的原子
  returnedNodeId: "T7",           // 当前返回的表头节点
  nodeBadges: { "A2": "#1", "L3": "#2" } // 长度/深度图像徽标
}
```

`highlightPointers` 的格式为 `节点ID.child` 或 `节点ID.next`。

实现中会对节点、变量和徽标做快照拷贝；播放器只读取当前索引，不会在渲染时临时计算操作结果。

### 分段逻辑

- **创建/解析**：读取字符 → 判断类型 → 分配节点 → 设置 tag / 原子值 → 连接 child/next → 递归子表 → 返回 → 完成；
- **求深度**：进入节点 → 判断空指针/原子/空表/表 → 初始化最大值 → 递归 child → 比较并更新最大值 → 返回；
- **求长度**：初始化 p 和 len → 循环判断 → 计数 → 沿 next 移动 → 到 NULL 返回；
- **取表头**：检查空表 → 高亮根节点的 child → 返回已有节点；
- **取表尾**：检查空表 → 定位首元素 → 新建 LIST 表头 → 连接剩余链 → 返回临时节点；
- **遍历**：进入表 → 递归 child / next → 原子按访问顺序追加。

## 验收用例

输入 `(a,(b,c),d)` 并点击“开始演示”：

1. **创建/解析**：最终生成 6 个节点；图中有根表、原子 `a`、子表 `(b,c)`、原子 `d`；
2. **求长度**：结果 `长度 = 3`，三个顶层元素分别出现 `#1`、`#2`、`#3` 徽标；
3. **求深度**：结果 `深度 = 3`，节点出现 `d1`/`d2`/`d3` 徽标，左侧显示三层标尺；
4. **取表头**：结果 `a`；
5. **取表尾**：结果 `((b,c),d)`，画布下方出现虚线返回表头；
6. **遍历**：结果为 `a, b, c, d`，完成后四个原子显示绿色勾选。

## 开发自测

`app.js` 在无 DOM 环境下通过 `module.exports` 暴露纯逻辑，可直接用 Node 验证：

```js
const g = require('./app.js');

const run = g.generateRun('(a,(b,c),d)', 'depth');
console.log(run.steps.at(-1).result); // 深度 = 3
console.log(run.steps.at(-1).nodeBadges);
console.log(run.steps.at(-1).codeLine, '/', run.codeBlock.lines.length);

console.log(g.generateRun('(a,(b,c),d)', 'length').steps.at(-1).result);
console.log(g.generateRun('(a,(b,c),d)', 'tail').steps.at(-1).result);
console.log(g.generateRun('(a,(b,c),d)', 'traverse').steps.at(-1).result);
```

也可以运行：

```bash
node --check app.js
```

浏览器端会在 `window.GLGame` 上暴露同一组只读逻辑，便于调试。
